# CareConnect — Elderly Care & Medication Management

CareConnect is an accessible web platform designed specifically for older adults to simplify daily medication tracking, routine management, and emergency SOS support.

## Problem Statement
Older adults often struggle with complex digital interfaces, leading to missed medication schedules and delayed assistance during emergencies. CareConnect bridges this gap by offering a high-contrast, easy-to-navigate interface tailored to senior citizens' daily healthcare and safety needs.

## Key Features
- **High-Contrast Accessibility:** Built with clear typography and accessible color contrast to ensure effortless readability for seniors.
- **Medication Tracking & Routines:** Simple daily schedule management to track medicines and routine tasks without confusion.
- **Emergency SOS Support:** Quick-access emergency alert functionality for immediate help when needed.
- **Clean & Lightweight UI:** Fast-loading, distraction-free interface designed for ease of use across devices.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Hosting & Deployment:** Vercel
